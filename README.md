## 🧑‍💻 Sobre Mí

- 🛡️ **Desarrollador Full Stack con enfoque en seguridad**: me importa tanto que el producto funcione como que sea difícil de romper.
- ⚙️ Diseño y despliego **APIs y microservicios contenedorizados**, con pipelines de **CI/CD** y prácticas **DevSecOps** integradas desde el primer commit.
- 🔎 Aplico **hardening, análisis de vulnerabilidades y automatización de seguridad** sobre la infraestructura que construyo, no como un paso final.
- 🐍 Uso **Python** para **procesamiento y análisis de datos**: limpieza, transformación y scripts que eliminan horas de trabajo manual.
- ☁️ Trabajo cómodo entre **Linux, Docker y la nube**, cerrando el ciclo completo: del código al despliegue monitoreado.
- 🌱 Actualmente profundizando en **arquitecturas cloud escalables** y **observabilidad**.
- 🤝 Abierto a colaborar en proyectos **open source** que mezclen **web + seguridad + automatización**.
- 💬 Pregúntame sobre **Node.js, React/Next.js, Docker, Linux o seguridad de aplicaciones**.
